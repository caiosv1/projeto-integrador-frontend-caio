# projeto-integrador-frontend-caio
Meu projeto é um catálogo sobre os personagens do desenho animado o incrivel mundo de Gumball

code review:

O projeto apresenta uma boa estrutura para um trabalho introdutório de HTML. Foram utilizados elementos importantes como títulos, parágrafos, listas, tabelas, imagens, links, formulários e elementos semânticos como header, main, section e footer. De forma geral, o projeto está bem organizado e apresenta uma proposta clara de catálogo sobre os personagens de O Incrível Mundo de Gumball.
O QUE ESTÁ BOM:
1.	Estrutura HTML5
O projeto utiliza DOCTYPE, html, head e body, formando a estrutura básica de uma página HTML.
2.	Organização semântica
A segunda versão utiliza corretamente elementos como header, main, section e footer, deixando o conteúdo mais organizado e semântico.
3.	Tabela
A tabela apresenta informações dos personagens, como nome, idade e espécie. A estrutura básica de linhas e colunas está correta.
4.	Formulário
O formulário é um dos pontos positivos do projeto. Foram utilizados campos de texto, e-mail, seleção de personagem, nota numérica, comentário e botão de envio.
5.	Validação dos campos
O uso de required nos campos de nome e e-mail é positivo. Também foi utilizado min="1" e max="10" para limitar a nota do personagem.
6.	Imagem
A imagem utiliza o atributo alt, o que é importante para acessibilidade.
7.	Organização das pastas
O caminho assets/images/capa.jpg está de acordo com uma estrutura organizada de projeto.
